# Hisopi

O Hisopi é uma aplicação multiplataforma que tem como objetivo ajudar a reduzir o desperdício de alimentos. Essa tarefa é realizada através de uma política FEFO no cadastro de alimentos, ou seja, os primeiros produtos cadastrados são os primeiros que aparecem no sistema e os que possuem prioridade em serem utilizados. Além do aplicativo, é fornecido uma API para integrar a diferentes sistemas.
As funções CUDA que poderiam ser implantadas no projeto seriam de cálculo de demanda e tempo até um insumo estragar e cálculo de reabastecimento do estoque.
